# Governance templates

Empty forms. Copy a file, replace each `<placeholder>`, and keep the filled copy with the work it records. The files in this kit stay blank.

- [Decision record](decision-record.md) — id, date, decider, context, options, decision, consequences, and what it replaces.
- [Autonomy ladder](autonomy-ladder.md) — what an agent may do alone, what needs a human yes, and defaults for money, public speech, and an irreversible step.
- [Agent role card](agent-role-card.md) — name, purpose, owns, does not own, inputs, outputs, escalation, and review gate.
- [Extend, never duplicate](extend-never-duplicate.md) — search first, extend, link instead of copy, and record why a new file exists.

No network. No filled-in example.
