# Kits

- [Kintsugi audit](kintsugi-audit/README.md) — a weekly, read-only gap audit.
- [Public-copy leak check](public-copy-leak-check/README.md) — scan pages with a phrase file you supply.
- [Safe helpers](safe-helpers/README.md) — dry-run send, a token bucket, and an export scrubber.
- [Review gate](review-gate/README.md) — allow a merge only when a verdict says PASS for the current head.
- [Hash allowlist runner](hash-allowlist-runner/README.md) — run a script only when its sha256 is allowlisted and the git tree is clean.
- [Governance templates](governance-templates/README.md) — empty forms for a decision, an autonomy ladder, an agent role, and a do-not-duplicate check.
