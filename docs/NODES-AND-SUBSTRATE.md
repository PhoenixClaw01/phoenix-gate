## Spine

```
[0] Stack DNA          named intents · Founder last-yes
[1] Gate               allow / deny / ask_human · receipts
[2] Packets            intent · bounds · won’t · AUTHORIZE
[3] Tenant faces       field faces on one spine (private)
```

DNA names what may proceed. The gate enforces that and writes a receipt. Packets carry intent, bounds, and what will not be done. Tenant faces stay private. Capture seats are a soft field ask, not an open-sourced product in this tree.

## Surfaces

Permissionless sovereignty surfaces on the same policy loop. None of them is a model SKU. Workers stay model-agnostic.

| Surface | Role |
|---------|------|
| CLI | Local last-yes and receipt inspect |
| MCP | Tool calls arrive already shaped for the gate |
| HTTP API | Verify / approve for peers who are not in-process |
| Plugins | Host-specific seams (hooks, proxies) without a new religion |

## Nodes

A **node** is optional compute: community machines, or Osmantic-class workers, running small-biz workloads **under Gate receipts**. The receipt is the warrant. The node is a watershed.

- The kit runs on a laptop with no node attached.
- A node does not bypass named locks or Founder last-yes.
- “Osmantic-class” names a shape of compute (verify-shaped, receipt-bearing). It is not a signed partnership and not a claim that anyone else operates these nodes.
